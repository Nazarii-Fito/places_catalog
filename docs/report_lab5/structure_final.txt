Структура проєкту наприкінці ЛР №5 (BLoC + локальне сховище)

Каталоги lib/
  app/                      MaterialApp (app.dart), іменовані маршрути, AuthGate (BlocBuilder на AuthBloc),
                            UserScope (блоки користувача над Navigator), параметри запуску для скриншотів
  core/                     тема й токени, UI-компоненти (PrimaryButton, AppTextField, ErrorState, …),
                            валідатори, AuthFailure, константи (AppStrings, AppAssets)
  data/models/              Place, Review, PlacePhoto, PlaceCategory (toJson/fromJson), AppUser, UserStats
  data/repositories/        інтерфейси (AuthRepository, PlacesRepository, SettingsRepository) і реалізації:
                            Firebase / Fake / InMemory / LocalPlaces (JSON-файл) / SharedPrefsSettings
  data/services/            AnalyticsService, CrashReporter (обгортки Firebase)
  features/session/bloc/    AuthBloc — сесія застосунку
  features/auth/            екрани Login / Register / Forgot Password; bloc/: LoginBloc, RegisterBloc, ForgotPasswordCubit
  features/places/          екрани Details / PlaceForm / Location Picker; bloc/: PlacesBloc (CRUD каталогу)
  features/home/            екран Home (slivers); bloc/: CatalogViewCubit (пошук, фільтр, сортування)
  features/favorites/       екран Favorites (представлення того самого каталогу)
  features/profile/         екрани Profile / Edit / Change Password / Export; bloc/: ProfileBloc, ChangePasswordCubit
  features/shell/           MainShell — вкладки (IndexedStack)
