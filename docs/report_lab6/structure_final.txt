Структура проєкту наприкінці ЛР №6 (Firestore, Supabase Storage, мапа)

Каталоги lib/
  app/                      MaterialApp, маршрути, AuthGate, UserScope (блоки користувача над Navigator), параметри запуску
  core/                     тема, UI-компоненти (PlaceImageView, OsmTileLayer, ErrorState…), валідатори, типізовані помилки
                            (AuthFailure, PlacesFailure, GeocodingFailure), константи (MapDefaults)
  data/models/              Place, Review, PlacePhoto (asset/local/remote), GeocodingResult, PickedLocation, AppUser
  data/firestore/           PlaceMapper (модель ↔ документ), PlacesDocumentStore + реалізації Firestore / in-memory
  data/repositories/        інтерфейси й реалізації: Places (Firestore / файл / пам'ять), Media (Supabase / Fake / NotConfigured),
                            Geocoding (Nominatim через dio / Fake), UserProfile, Settings, Auth
  data/services/            Analytics, CrashReporter, PhotoPickerService (image_picker), MapLauncher (url_launcher),
                            PhotoUploadSession (завантаження з відкатом), SupabaseConfig
  features/session/bloc/    AuthBloc
  features/auth/            екрани входу; bloc/: LoginBloc, RegisterBloc, ForgotPasswordCubit
  features/places/          екрани Details / PlaceForm / Location Picker; bloc/: PlacesBloc, CreatePlaceBloc, UpdatePlaceBloc,
                            LocationPickerCubit
  features/home/            Home; bloc/: CatalogViewCubit
  features/favorites/       Favorites
  features/profile/         Profile / Edit / Change Password / Export; bloc/: ProfileBloc, ChangePasswordCubit
  features/shell/           MainShell

Файли конфігурації: firestore.rules, firebase.json (розділ firestore), env/supabase.example.json,
.vscode/launch.json, android/…/AndroidManifest.xml (INTERNET, queries), ios/Runner/Info.plist (камера, фото)
