# Підписи до скриншотів ЛР №6

Кадри 1–2 — звичайна збірка з **реальними тайлами OpenStreetMap** і реальним запитом до Nominatim (каталог у локальному режимі `PLACES_BACKEND=local`, без Firestore). Кадри 3–4 — режим скриншотів `FAKE_AUTH` (без мережі). iPhone 17.

- **Рис. 1.** Вибір локації: інтерактивна мапа OpenStreetMap, нерухомий пін по центру, скляна панель пошуку, нижня картка з назвою, адресою (знайдена reverse geocoding через Nominatim), координатами й кнопкою Confirm Location; видима атрибуція «© OpenStreetMap contributors».
- **Рис. 2.** Place Details: секція «Location & Coordinates» — міні-мапа без взаємодії з маркером закладу й підписом адреси; тап по мапі або «Open in Apple Maps» відкриває зовнішній застосунок Карти.
- **Рис. 3.** Action sheet вибору джерела фото (Take Photo / Choose from Library / Cancel) на формі закладу.
- **Рис. 4.** Форма закладу з обраними фото (прев'ю з локальних файлів, видалення хрестиком, лічильник «2 left»).

> Скриншоти консолей Firestore і Supabase, прогресу завантаження й роботи без мережі знімає автор (`../screenshots_todo.md`).

## Після доробок (мапа з закладами, геолокація, аватар)

- **Рис. 5.** Вибір локації після натискання «My location» (кнопка зі стрілкою під пошуком; розташування симулятора — центр Львова): мапа центрована на користувачі, картка показує адресу «Вежа Ратуші, 1, Площа Ринок», навколо — маркери закладів (кав'ярні, ресторани, бари, паби) з Overpass API; тап по маркеру вибирає заклад і підставляє його назву й категорію у форму.
- **Рис. 6.** Edit Profile: окрім пресетів і посилання з'явилась кнопка «Upload from Device» (камера або бібліотека); вибране фото показується одразу, а на Save завантажується в Supabase й стає `photoURL`.
